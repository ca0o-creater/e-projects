# 嫦娥奔月 · 第一幕「后羿得药」

Vite + TypeScript + PixiJS v8 展位全屏舞台。初始显示深棕色幕布与“进入体验”按钮，点击后进入全屏并启动舞台；按 Esc 退出后隐藏舞台、暂停 PixiJS ticker，恢复进入按钮。

舞台逻辑尺寸固定为 1920×1080，按 `Math.min(窗口宽 / 1920, 窗口高 / 1080)` 等比缩放并居中，空余区域保持深棕色。左上角保留实时视口宽高。全屏被拒绝时显示提示，允许再次尝试。

第一幕布景全部由 PixiJS 绘制，没有外部图片：米黄宣纸、中央暖光、顶部三层云纹、左右各三层黛蓝山峦。暖光使用径向渐变与 BlurFilter，自中心向四周自然变暗；透明度每 8 秒在 0.695–0.745 间轻微变化。云山背后有偏移的深褐色模糊投影。纸纤维、山峦阴影和灯光滤镜缓存后复用，动画期间不重复生成图形。

参数统一放在 `src/config/act-one.ts`：`colors` 调色，`light` 调光晕和呼吸，`shadows` 调投影，`mountains` 调山峦宽度和粗糙度，`clouds` 调云的速度/透明度/位置，`title` 调题字节奏。速度单位为逻辑像素/秒，时长为秒。

默认山峦仅占左右各 210 像素，高度缩至原来的 42%，固定在底部两角。中央表演区为 x=270–1650（约占舞台宽度 72%）、y=300–1050。后羿根节点移至 (700,920)，西王母落点移至 (1260,360)，人物、接药手臂及操纵杆均避开两侧山体。

入场先展示布景，1.2–4 秒题字降下，完整停留 2 秒，6–7.8 秒淡出。这期间人物和药瓶均不出现。题字完全消失后留出 0.3 秒间隔，8.1–9.5 秒后羿淡入，9.5–12.5 秒西王母下降并淡入。人物就位后药瓶开始发光，13.3 秒进入赐药阶段，约 14.9 秒可以拖动。人物入场时间由题字总时长推导，调整题字节奏后会自动顺延。退出全屏或切换到后台时暂停，重新进入继续；刷新页面从头播放。

人物参数在 `src/config/characters.ts`：初始位置、缩放、关节长度、初始角度、图层、投影和入场时长。占位形状及部件尺寸集中在 `src/characters/puppets.ts`。后羿骨架是 root → torso → head / upperArm → forearm；肩、肘 pivot 都为局部 (0,0)，肘位于大臂末端。默认手臂自然下垂，可用 `HouyiPuppet.setArmPose(肩角度, 肘角度)` 调整姿势，投影会同步。

替换图片时，保留部件 Container 的位置、pivot 和父子层级，只替换其中的 Graphics 美术；将 Sprite 的肩/肘对齐到容器局部原点。骨架工厂也生成投影副本，更换素材时应同步提供相同轮廓的深褐色投影。药瓶入场时挂在 `QueenPuppet.palm` 上，西王母赐药动作结束后转入独立的交接图层。

题字结束、人物入场并稳定后出现“拖动发光的药瓶，交给后羿”，西王母用 1.6 秒伸出手臂，然后药瓶可被抓取。鼠标左键按住药瓶沿左下方拖动，位置投影到三次贝塞尔曲线上，弧长进度同步驱动后羿肩、肘关节。距离当前后羿手部 100 个逻辑像素内自动锁定吸附，提示“已接住，可以松手了”。松手后播放光环与光点，手臂收回、药瓶淡出，解锁凡间。半途松手沿原曲线回到西王母掌心，显示“请重新尝试”。按 Esc、切换窗口或指针取消不会误判交接成功。

右下角“辅助完成”走同一成功流程；重复松手和重复点击不会重复解锁。点击“前往凡间”销毁第一幕并进入第二幕 `scene2_intro`，同时派发 `navigate-to-mortal` 事件。成功事件 `mortal-unlocked` 每次页面加载至多一次，刷新可重新体验。

交互架构：

- `src/input/semantic.ts` 定义 `GRAB { point }`、`MOVE { point }`、`RELEASE { cancelled? }`；point 使用舞台的 1920×1080 逻辑坐标。
- `src/input/pointer-adapter.ts` 处理指针捕获、坐标换算、单指针限制、松手及取消，独立于剧情。
- `src/interaction/handoff.ts` 是不依赖 DOM/PixiJS 的状态机，接收 `scene.handoff.input(event)`。未来 MediaPipe 只需换适配器，映射摄像头坐标并派发同样的语义事件；丢失追踪发送 `RELEASE { cancelled: true }`。
- `src/interaction/curve.ts` 负责弧长参数化、最近点投影与曲线取点。
- `src/characters/poses.ts` 负责肩肘姿势和手心正向运动学；`src/scenes/act-one.ts` 根据状态更新人物、拖尾与成功光效。
- `src/config/handoff.ts` 集中赐药时长、接药姿势、曲线控制点、抓取与吸附半径、返回和收臂时长、光效参数。

## PNG 人物与 IK（当前版本）

当前运行时已采用 `public/assets/houyi.png`（后羿-背面藏杆）和 `public/assets/queen.png`（西王母-瑶池清韵，下半张皮影），覆盖上文的占位剪影方案。源图为 1024×1536 的带纸底整图；没有修改源图，使用 Pixi 多边形遮罩划分后羿躯干、右上臂、右下臂，并裁出西王母主体。遮罩仍有纸底残留和近似轮廓，不能当作已经精修的透明分层美术。后羿左臂固定，弓为固定 Graphics 占位；西王母袖臂尚未拆分，保持原图姿态，采用整体悬浮和固定手部末端挂点，不再播放独立抬臂动作。

`src/config/rig.config.ts` 是本轮的校准入口：

| 字段 | 微调用途 |
| --- | --- |
| `houyi.shoulder / elbow / hand` | 原图肩圆环、肘圆环、掌心坐标；臂长 `armLengths` 根据两段距离与 scale 自动推导 |
| `houyi.upperArm/forearm.pivotOffset` | 每块美术的原图转轴，与对应肩/肘坐标保持一致 |
| `upperArm/forearm.baseRotation` | 原图部件方向补偿，使局部骨骼统一沿 +Y；改变关节坐标后需同步校准方向 |
| `textureSize` | 原 PNG 尺寸，加载时检查，所有部件共用这一纹理尺寸 |
| `body/upperArm/forearm.polygon`、`bodyHoles` | 外轮廓与镂空区域遮罩，用于精修边缘与清理纸底 |
| `houyi.origin / scale` | 人物的局部原点与美术尺寸 |
| `houyi.rest / limits` | 自然下垂角度与肩肘旋转边界 |
| `queen.handOffset / origin / scale` | 药瓶挂点与主体定位 |
| `queen.floatAmplitude / floatPeriod` | 整体悬浮幅度与周期 |
| `queen.armLimits` | 为未来分层袖臂预留的 -30°～45°范围，当前固定袖臂不使用 |
| `targetBounds / resetSeconds` | 输入边界与平滑复位时间尺度 |

`image-rigs.ts` 以负 pivotOffset 放置 Sprite，部件校正旋转放在美术子容器中。骨架为 root → torso → shoulderNode → upperArm 容器 → elbowNode → forearm 美术 / handNode。美术的缩放与 baseRotation 不会污染子关节的坐标。原占位骨架工厂保留用于兼容旧测试，页面实际使用 createImageHouyi。

`ik.ts` 解算两个刚性链杆：目标过远时伸直，过近时钳制到内圆，可达目标使用余弦定理，选择肘部屏幕 Y 较大的分支。药瓶路径点先转换到肩的局部空间，再解算肩肘角度。无效数字被拒绝，越界输入或失焦取消本次拖动并平滑复位。吸附后的收臂期间药瓶跟随实际 handNode，避免与手部脱离。

验证：进入体验等人物出场；拖动药瓶观察右肩和右肘，半途松手检查复位，将鼠标拖出舞台检查取消；再次拖到后羿附近松开检查解锁。开发时可用 `?preview=act-one&skipIntro=1` 跳过题字与入场。

### 接药弯肘与缓动修正

接药终点改为 `rig.config.ts → houyi.receiveTarget`（肩部局部坐标 x=100、y=-15），确保进入臂展内部。原终点处于最大臂展，配合提前吸附会让 IK 一直伸直。现在拖动直接使用药瓶坐标解 IK，回收阶段缓动至固定 rest，运行时不再采用进度到关节角度的映射。肩肘的两块 PNG 遮罩保持独立，圆环铆钉盖片由 `jointCoverRadius` 调节。

`houyi.followSeconds=0.14` 控制追随重量感；`resetSeconds` 控制复位。使用最短角度差的指数缓动，避免角度跨 ±π 绕远。`handoff.snapMinProgress=0.97` 延后吸附，保留末段弯肘过程；容错半径依然是 100 逻辑像素。

西王母在入场完成后从零位连续接入上下浮动，幅度 10 逻辑像素，周期 5 秒。等待抓取的药瓶随手部悬浮，抓取后使用固定曲线。

测试时慢慢拖到后羿胸前上方：远处先伸臂，进入近处后肘明显弯曲；看到松手提示时先保持按住，检查肩肘接缝和追随效果；松手后收臂。半途松手应平滑复位。刷新后观察西王母与药瓶一起浮动。

### 操偶结构与幕布融合

每位人物身后各有躯干杆和手部杆，端点每帧从骨架转换为舞台坐标，随入场、悬浮、IK 和收臂同步移动。后羿肩肘及西王母手腕绘有带高光的金属圆环。人物通过 GlowFilter 输出正片叠底到幕布；滤镜内部保留正常混合，避免透明离屏纹理导致人物变黑。药瓶独立于人物滤镜，保留发光亮度。人物与杆件均带向下偏移的柔影，整幅舞台增加固定种子的轻微 NoiseFilter 颗粒。

- `src/config/puppet-look.ts`：竹签宽度/颜色、底端位置、躯干挂点、圆环大小/颜色、边缘微光强度。
- `src/config/rig.config.ts → queen.wrist`：西王母腕部圆环的原图坐标；后羿圆环直接绑定肩肘节点。
- `src/config/act-one.ts → mountains / grain`：两角山体宽高和幕布噪点强度。
- `src/config/characters.ts → houyi / queen`：人物位置及入场落点。

检查时先观察待机姿态，再缓慢拖药至吸附但暂不松手：四根竹签应位于人物下层，手杆端点跟随手部，肩肘圆环始终盖在接缝上。人物和竹签都不应碰到两角山体。开发用 `tests/rig-preview.html` 可查看固定的接药弯肘画面。

## 第二幕：凡间 · 嫦娥吞药

第一幕完成后点击“前往凡间”，进入 `scene2_intro`。庭院使用 `public/assets/scene2_bg.png`（本轮附件原图）；树与房屋整体水平翻转，固定放大并左移裁切，左边露树，房屋占约四分之三。原来的 Graphics 亭子和地台已删除；顶部暗月、0.4 黑色遮罩位于人物之下。

剧情按场景 ticker 顺序推进：0.6 秒后羿从中左侧向左走并淡出，4.4 秒消失；4.75 秒逢蒙从左边缘向右逼近，带轻微步伐起伏，9.15 秒停稳；显示“逢蒙持刀逼迫，嫦娥护药”，保持 2.2 秒并淡出 0.6 秒，约 11.95 秒才解锁手腕操作。台词显示期间仍不能抓取。

`src/config/scene2.config.ts` 是第二幕参数入口（`act-two.ts` 仅作兼容导出）：
- `background.scale / x / y / flipX / nightOpacity`：庭院构图与夜色；x/y 为翻转后图片左上角。
- `departingHouyi.startX / endX / y / scale`：后羿离家起点与终点；终点额外校验人物完整离场。
- `pengMeng.startX / endX / y / height / flipX`：逢蒙从左向右的路径；终点保留与手腕操作区的安全距离。
- `pengMeng.walkAmplitude / walkHz / jitterAmplitude / jitterHz`：步伐起伏与停稳后微抖。
- `changE.x / y / scale`：嫦娥屋内位置与大小；手腕圆弧自动按同一组骨架参数重新计算。
- `intro`、`captions`、`moon`：剧情时长、台词位置与暗月参数。

嫦娥、后羿、逢蒙均使用现有 PNG，人物遮罩与皮影混合效果保留。嫦娥的原图铰链坐标仍在 `change-rig.ts`，掌心挂点、瓶子、光圈与弧线保持对齐。逢蒙当前素材带纸底，运行时近似轮廓遮罩；若替换为真正透明 PNG，将 `pengMeng.usePaperMask` 改为 false。

## 第三幕：奔月相思

第二幕完成后点击“月宫”，清理旧显示树、滤镜、场景ticker和指针监听，进入 `scene3_intro`。2.5秒入场后，拖动嫦娥腰部主杆光圈升空，X锁定，仅Y轴映射0–1进度。背景使用 scene3_bg.png 的亭子、云纹与天空，原几何云朵、地面和后羿已删除。嫦娥从亭内以实际 scale=0.2 起飞，随进度增至 0.8；背景下移 420 像素，叠加渐深的蓝色渐变，月亮同步放大变亮。右下角以深色矩形遮挡水印。环境只由进度驱动，中途松手或输入取消会保留高度和全部环境状态，再次抓取无跳变。

达到95%并保持按住停稳400ms，显示“松手，飞入月宫”；合格松手进入 `scene3_complete` 并锁定输入，播放2.4秒入月淡出与0.8秒月晕脉冲。随后显示“清冷月宫，相思无尽”、“重演”（从第一幕重新开始）与“知识回顾”（打开故事与皮影操演回顾面板）。辅助升空按钮必须持续按住，进度每秒增加0.13，到顶停稳后自动收尾；提前松开、失焦、Esc均停在当前位置。

`src/config/scene3.config.ts` 集中舞台、角色起止位置、腰部挂点、初末缩放（character.startScale/endScale）、月亮尺寸、背景位移（background.travel）、夜色渐变（night）、辅助速度、停留判定和收尾时长。原图像素坐标仍共用 `change-rig.ts`，无需重复校准原图。

开发入口 `http://127.0.0.1:5173/?preview=act-three`；加 `&skipIntro=1` 直接交互。仅开发可用 `&pose=complete` 通过真实控制器更新得到结尾，用于检查重演/回顾；正式构建没有这条捷径。

### 第三幕电影结尾

第三幕挂载时预载 `public/assets/ending_cry.mp4`。入月消散和月晕脉冲结束后插入顶层 video，首个解码帧到达才隐藏 Canvas 与旧 UI。视频静音自动播放、无控制条、object-fit: cover；当前素材约5.04秒，以约1.26倍速完整播放为4秒。原文件不修改。

ended 后，末帧在700ms内淡出，底层为深灰色；字幕随后淡入，1600ms后按钮开始淡入并开放。视频加载失败、播放被拒绝、首帧6秒超时或播放卡住4秒均回退到结尾。重演会释放视频、计时器、DOM节点和事件监听。最终场景状态为 ending，舞台输入不再响应。

调整 `scene3.config.ts` 的 `ending` 和 `video` 可修改入月时长、缩小倍率、月晕强度、视频路径、播放目标时长与淡入时间。
